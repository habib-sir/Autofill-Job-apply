⚙️ How Phone SMS Sync Works
Method 1: Instant Mobile Web Companion (No APK)

Simply scan the QR code with your Android phone's camera. When you click "Send SMS" in the extension, the companion rings/vibrates on your phone and opens the pre-filled SMS in your default Messages app. Tap send on your Teletalk SIM!

Method 2: Android SMS Gateway APK (100% Silent Background)

Install the free, open-source Android SMS Gateway APK. It listens to the extension's REST webhook and automatically sends SMS from your Teletalk SIM and syncs replies completely in the background without needing to tap your screen!

Method 3: MacroDroid / Automate (Play Store)

Use MacroDroid to trigger on incoming SMS from 16222 and forward the payload to /api/sms/incoming via HTTP POST.

MacroDroid is a free automation app on Google Play with full SMS access. It sends SMS via Teletalk automatically when commanded by your extension!

  1. Install MacroDroid from Google Play Store.
  2. Grant MacroDroid SMS Permissions in Phone Settings.
  3. Add a Macro with Action: Send SMS → Recipient: 16222 → SIM: Teletalk.
  4. Trigger on Webhook using the Gateway URL and Token above.
📄 Detailed step-by-step guide saved in: /android-sms-gateway/macrodroid-guide.md

Run our automated gateway script inside Termux on your phone (takes 2 commands, completely free):

pkg update && pkg install -y termux-api jq curl
curl -O http://.../android-sms-gateway/termux-gateway.sh
bash termux-gateway.sh

When prompted, tap Allow for Termux:API SMS permissions. Termux will run quietly in the background, send SMS to 16222 via Teletalk, and sync replies!

The project includes the complete production-grade Android Studio source code inside /android-sms-gateway/:

  • AndroidManifest.xml with SEND_SMS and RECEIVE_SMS
  • MainActivity.java: UI with Teletalk SIM selector & live logs
  • SmsGatewayService.java: Persistent Foreground Service that auto-sends SMS
  • SmsReceiver.java: Intercepts 16222 replies and auto-syncs PIN to PC
💡 Open /android-sms-gateway in Android Studio and click Run to install directly onto your connected phone via USB or Wi-Fi.
