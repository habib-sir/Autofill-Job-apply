# Autofill Job Apply – এক ক্লিকে চাকরির আবেদন (Bangladesh)

**Autofill Job Apply** is a browser extension and automation tool designed specifically for **Bangladeshi government job applications** on **teletalk.com.bd** and other e‑recruitment portals. Save your CV once, and the tool will automatically fill every application form with your information – name, address, education, experience, and more – with just one click.

## 🎯 Problem it solves

Applying to Bangladeshi government jobs usually means re‑typing the same CV details on dozens of different portals (e.g., `*.teletalk.com.bd`). This is time‑consuming and error‑prone.

**Autofill Job Apply** eliminates that hassle:
- 📝 **Save your CV once** – securely store your personal, educational, and professional details.
- ⚡ **One‑click autofill** – open any job application form on a supported portal and click the extension icon. All fields are filled automatically.
- 🧠 **Smart field mapping** – the tool understands the structure of Bangladeshi e‑recruitment forms, including fields like `Father's Name`, `Mother's Name`, `Quota`, `National ID`, etc.
- 🔁 **Reusable across all teletalk.com.bd sites** – works on every government job portal hosted under teletalk.com.bd.

## 🚀 Features

- ✅ Works on all `*.teletalk.com.bd` job application sites
- ✅ Saves your CV data locally (no cloud, full privacy)
- ✅ One‑click autofill with a browser extension or keyboard shortcut
- ✅ Handles dropdowns, radio buttons, checkboxes, and date pickers
- ✅ Supports both English and Bangla (Unicode) text fields
- ✅ Option to export/import your CV profile
- ✅ Lightweight and fast – no lag while filling

## 📦 Installation

### Option 1: Browser Extension (Recommended)
1. Download or clone this repository:
   ```bash
   git clone https://github.com/masterboom2040-ai/Autofill-Job-apply.git

2. Open your Chrome/Brave browser and go to chrome://extensions.
3. Enable Developer mode (top‑right corner).
4. Click Load unpacked and select the extension/ folder from the cloned repository.
5. The extension icon will appear in your toolbar.
